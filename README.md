# 🎛️ UI Master Tweaker

A Transport Tycoon user app for restyling and rearranging your in-game UI: menus, chat, prompts and the money, bank and job display. Settings apply instantly and save automatically.

## Install

1. In game, press **F1**.
2. Paste this address into the user app box:

   ```
   https://hellogoobie.github.io/master-ui/
   ```

3. Pick a theme. It applies straight away.

Press **F1** at any time to bring the app back if it is hidden.

## Features

### 🎨 Themes
- 40+ menu themes and 20+ chat themes, from clean (Midnight, Nord, Dracula, Clean Light) to fun (Smartphone with app icons, RuneScape-style, Minecraft, Windows 95, Pokémon, Comic Book).
- **Apply theme to everything** styles the menu, prompts, requests, announcements, money/bank/job display and chat together, using the chat theme with the same name when there is one.
- Chat box **opacity** and chat **tab size** sliders.
- Optional **Custom CSS** box for your own styling.

### 📐 Layout
- Move and scale the menu, menu description box, text prompts, requests, announcements, progress bars, money, bank, job and chat.
- **Auto-fit** picks sizes for your screen resolution.
- **Reset ALL elements** puts everything back to its original position and size.

### 🪟 The app window
- Drag the title bar to move the window anywhere on screen. It remembers where you left it.
- Choose what happens when you click outside the app: hide it, keep it on screen, or do nothing.

## Good to know

- **Menu styling works out of the box.** It uses the game's own user app commands, so there is nothing to set up.
- **Chat styling connects in the background.** The dot on the Themes and Setup tabs shows whether it is connected. If it stays disconnected, the Setup tab has manual steps.
- Everything is saved in your browser for this address. If the app's address changes, your saved settings start fresh.
- There are no pop-up boxes, so the app cannot soft-lock the game.
- Themes rely on the game's own menu and chat, so a game update could change how some of them look.
- If something looks wrong, use **Reset everything to defaults** on the Setup tab.

## Backup and sharing

The Setup tab can create a **backup link** that contains your settings. Only share it with people you trust, because it can include custom CSS.
